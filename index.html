About Math Hub

Our Mission

Math Hub is a student-led initiative designed to make learning math more engaging, collaborative, and accessible.

We believe that peer-to-peer support is one of the most effective ways to learn, which is why we've created this platform to connect students with resources, track their progress, and feel motivated to succeed in mathematics.

Planning & Development (FBLA)

This website was designed and developed for the FBLA Website Design competition, addressing the 2025-2026 topic: "Design to Learn: Build a Student Learning Hub."

  • User-Centered Planning: We identified core student needs: resource access, progress tracking, and personalized help.
  • Modern Design: We chose a vibrant, responsive layout with modern gradients and animations to create an engaging user experience.
  • Interactive Implementation: Built as a single-page application (SPA) using HTML, Tailwind CSS, and JavaScript to be seamless and fast.
